# Divine Gateway

Create a premium, elegant, fully responsive Ganpati invitation website with a beautiful traditional Indian festive aesthetic.

MAIN CONCEPT

The website should begin as a sealed wedding-style invitation envelope, but designed specifically for a Ganpati celebration.

The first screen should be a full-screen invitation envelope. The visitor must click the Ganpati stamp/seal to open the invitation.

The envelope opening should feel like a gate opening:

The stamp is placed prominently in the center of the envelope.

Add a subtle floating/pulsing animation to the stamp to indicate that it is clickable.

When the user clicks the stamp, animate the seal breaking/opening.

Then the envelope should open dramatically.

The left and right sides of the envelope should move outward like two gates opening.

The invitation website underneath should gradually be revealed.

Use a smooth, elegant animation lasting approximately 1.5–2.5 seconds.

Do NOT simply fade from one page to another.

The opening should feel luxurious, ceremonial and magical.

After the envelope opens, automatically reveal the main invitation and allow the visitor to scroll normally.

FIRST SCREEN / ENVELOPE

Create a full viewport opening screen.

Visual direction:

Deep royal purple / wine purple background.

Traditional Indian Ganpati invitation aesthetic.

Elegant gold decorative elements.

Subtle floral motifs.

Soft warm lighting.

Premium paper texture.

Traditional ornamental borders.

A large elegant envelope in the center.

Use the uploaded reference images as visual inspiration where appropriate.

Envelope:

Rich cream/off-white or warm ivory paper.

Gold ornamental border.

Traditional Indian decorative patterns.

Large circular Ganpati-inspired wax/seal stamp in the center.

The stamp should look tactile and realistic.

Add subtle shadow and depth to the envelope.

Text on opening screen:

"॥ श्री गणेशाय नमः ॥"

and below:

"With the blessings of Lord Ganesha"

Then:

"Tap the seal to open"

Make the "Tap the seal to open" text gently pulse.

ENVELOPE OPENING ANIMATION

This is the most important interaction.

Initial state:

Envelope is completely closed.

Stamp is visible in the center.

Main invitation content is hidden behind the envelope.

On clicking the stamp:

Stamp slightly scales down and breaks/open visually.

Envelope flap begins opening.

The envelope divides/opening panels move left and right.

The left panel rotates/slides toward the left.

The right panel rotates/slides toward the right.

Make the movement resemble large ceremonial gates opening.

Reveal the Ganpati invitation behind the envelope.

Add a soft golden glow during the transition.

Once fully open, hide/remove the envelope from the viewport.

Enable normal page scrolling.

The animation should work smoothly on both desktop and mobile.

Prevent accidental repeated animation clicks.

ANIMATIONS

Use subtle premium animations throughout:

Envelope opening animation

Stamp pulse

Gold glow

Fade-up section animations on scroll

Gentle floating flower petals

Subtle decorative particle effects

Image hover animations

Smooth scrolling

Gentle parallax where appropriate

Do not over-animate the page.

The website should feel like a luxury digital invitation, not a generic website template.

RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:

Large cinematic envelope

Full-screen opening animation

Spacious layouts

Tablet:

Adjust envelope size and typography

Mobile:

Envelope must fit within the viewport

Stamp must remain easy to tap

Gate-opening animation must work correctly

All sections must stack beautifully

Buttons must be touch-friendly

No horizontal scrolling

TECHNICAL REQUIREMENTS

Build the website using modern React.

Use clean reusable components.

Suggested structure:

StampSeal

HeroSection

InvitationMessage

EventDetails

PujaSchedule

BappaSection

LocationSection

GallerySection

RSVPSection

FinalBlessing

Use CSS animations or Framer Motion for the envelope/gate animation.

Important:

The envelope opening interaction must be functional, not just a visual mockup.

Clicking the stamp should trigger the complete opening sequence.

After opening, the user should be able to scroll through the invitation.

Ensure the animation does not cause layout or scrolling bugs.

Optimize images and animations for performance.

Keep all editable event information in one easy-to-find configuration/data section.

Make image placeholders easy to replace.

IMPORTANT VISUAL PRIORITY

The first impression is the most important part.

When the website loads, the visitor should immediately see a beautiful sealed Ganpati invitation envelope.

The experience should feel like:

"Receive invitation → click sacred seal → ceremonial gates open → discover the beautiful Ganpati invitation."

Do not make the opening screen look like a normal website homepage.

Make it feel like a luxury interactive Indian wedding invitation, adapted for Ganpati.

Use the uploaded reference images as inspiration for the visual direction, composition and aesthetic, while creating the website interaction described above.
